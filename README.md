**KALAIYĀTTIRAI** is an interactive 3D digital museum and scroll-driven chronological archive celebrating 4,500 years of unbroken civilizational creativity across the Indian subcontinent. From the enigmatic meditative glyphs of the Indus Valley Civilization (2600 BCE) to the opulent Mughal-era jaali filigrees and Himalayan miniature paintings, KALAIYĀTTIRAI brings South Asian art history to life through editorial luxury and high-definition archival imagery.

## Vision & Experience

Rather than presenting a static catalog or flat dashboard, KALAIYĀTTIRAI offers an editorial museum journey:

- **Chronological Immersion**: Travel seamlessly across four and a half millennia, organized by distinct aesthetic horizons, dynastic summits, and civilizational shifts.
- **Pan-Indian Breadth**: Balanced representation spanning 14+ Indian states and regions—from the rock-cut Dravidian temples of Tamil Nadu and Maharashtra to the terracotta sanctuaries of Bengal, the marble stepwells of Gujarat, and the fine crafts of Jammu & Kashmir.
- **Museum-Grade Visuals**: High-resolution, open-access archival photography sourced from premier heritage institutions, accompanied by indigenous script epigraphy (Devanagari, Grantha/Tamil, Sharada, etc.).
- **Art-Historical Rigor**: Curatorial dossiers incorporating analysis from seminal art historians including Ananda K. Coomaraswamy, Stella Kramrisch, and C. Sivaramamurti.

## Key Interactive Features

- 🏛️ **Chronological Era Chapters**: 18 narrative exhibits featuring dual-column layouts, primary quotes, historical context, dynastic patronage, dimensions, and dedicated *"What to Notice"* observation points.
- 🧭 **Floating Chrono-Rail**: An interactive vertical waypoint rail tracking your scroll position through time, with direct jump links and era badges.
- 🔍 **Limitless Macro Examination Studio**: Deep-zoom modal allowing inspection from 100% to **100,000%** zoom, with mouse-wheel scaling, multi-level presets, and frictionless drag-to-pan exploration.
- ⚖️ **Cross-Century Comparative Analysis Matrix**: Side-by-side juxtaposition of any two masterpieces to compare iconography, materials, patrons, and spatial dimensions across eras.
- 🗺️ **Regional Filtering & Curatorial Directory**: Instant sorting by geopolitical zone (North, South, East, West, Central, Pan-India).

## Limitless Macro Examination Studio

Clicking the **"Examine Artifact"** button on any exhibit activates the 4K Macro Inspection Studio:

- **Limitless Magnification**: Scale from 0.5x up to **1000x (100,000%)** without artificial clipping or arbitrary zoom boundaries.
- **Frictionless Pan**: Click and drag to inspect intricate bronze patinas, stone chiseling marks, or miniature brushwork.
- **Preset Quick-Selectors**: Dedicated buttons for `1.0x Reset`, `3.0x Macro`, `10.0x Deep Zoom`, and `25.0x Ultra Zoom`.
- **Zoom Status HUD**: Live readout indicating current magnification level.

## Comparative Analysis Matrix

The **"Compare"** module allows visitors to juxtapose any two artifacts across centuries:

- **Dual-Column Visual Comparison**: High-definition framed views of both selected artifacts.
- **Multi-Vector Analytical Dossier**: Side-by-side breakdown comparing Period, Geopolitical State, Dynasty, Medium/Material, Dimensions, and Historical Patronage.
- **Dynamic Selectors**: Quickly switch between all 18 masterworks to trace cross-cultural evolution.

## Architecture & Design System

KALAIYĀTTIRAI is built using a strict **single-file web architecture** (`index.html`), ensuring maximum portability, lightning-fast load times, and offline readiness.

### Color Palette
- **Obsidian Darkest**: `#070605` (Deep temple sanctum black)
- **Ancient Surface**: `#0f0d0a` & `#15120e` (Charcoal stone finish)
- **22K Imperial Gold**: `#d4af37` (Primary epigraphic accents)
- **Chola Bronze**: `#c47e3a` (Sculptural warmth)
- **Terracotta Red**: `#c95d3b` (Brick and clay heritage)

### Typography
- **Display / Epigraphy**: `Cinzel` (Classical Roman & Inscriptional serif)
- **Literary / Curation**: `Cormorant Garamond` (Elegant editorial serif)
- **User Interface**: `Plus Jakarta Sans` (Clean, contemporary legible sans-serif)

## Quick Start & How to Run

Because KALAIYĀTTIRAI has **zero external build steps or node module dependencies**, you can run it immediately with any static server or directly in your browser.

### Option 1: Direct File Open
Double-click `index.html` or drag it into any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Apple Safari).

### Option 2: Local Python Server (Recommended)
```bash
# Navigate to the project directory
cd "Interactive Timeline with Artifacts"

# Start Python HTTP server
python -m http.server 8080
```
Open [http://localhost:8080/index.html](http://localhost:8080/index.html) in your browser.

### Option 3: Node.js `npx serve`
```bash
npx -y serve -p 8080 .
```

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `Space` / `Down Arrow` | Scroll forward through chronological eras |
| `Up Arrow` | Scroll backward through time |
| `+` or `=` | Zoom in within the Macro Examination Studio |
| `-` or `_` | Zoom out within the Macro Examination Studio |
| `Escape` | Close any active modal (Studio, Compare, Sources) |
